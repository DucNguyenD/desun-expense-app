Ứng dụng quản lý tài chính cá nhân, giúp theo dõi thu chi, quản lý ví, đặt ngân sách và mục tiêu tiết kiệm.

## Chức năng

- Quản lý nhiều ví tiền.
- Ghi nhận thu, chi và chuyển tiền giữa các ví.
- Phân loại giao dịch theo danh mục.
- Đặt ngân sách chi tiêu theo tháng.
- Theo dõi mục tiêu tiết kiệm.

## Công nghệ

- Backend: Django + Django REST Framework.
- Frontend: React + TypeScript.
- Database: PostgreSQL.
- Lưu trữ file: MinIO.
